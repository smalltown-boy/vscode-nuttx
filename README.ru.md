
# Расширение VSCode для работы с Apache NuttX

Данное расширение предназначено для более удобного создания и сборки проектов для операционной системы реального времени Apache NuttX.

## Описание

Этот проект создан для разработчиков встроенного программного обеспечения микроконтроллеров, использующих операционную систему реального времени Apache NuttX. С его помощью большая часть работы автоматизируется, избавляя разработчика от постоянного ввода команд в терминал.  

## Функционал

* Простая настройка: перед началом работы нужно указать пути до папок `apps` и `nuttx` дистрибутива NuttX.
* Автоматическое создание папок и файлов проектов: файлы `Kconfig`, `Makefile` и `main.c` содержат необходимый минимум для начала работы.
* Ввод команд может осуществляться как при помощи командной строки VSCode, так и с помощью кнопок, расположенных на боковой панели редактора.
* Простой поиск целевого микроконтроллера по его полному, либо частичному наименованию (поддерживаемых самой операционной системой).

## Установка

### Сборка из исходного кода 
1. Установите Node.js и npm (Node Package Manager):

    ```bash
   sudo apt update
   sudo apt install nodejs npm
   ```

    После установки проверьте версии установленного ПО:

    ```bash
   node -v
   npm -v
   ```


2. Клонируйте исходный код расширения из репозитория:

    ```bash
   git clone https://github.com/smalltown-boy/vscode-nuttx.git
   cd vscode-nuttx
    ```
    
3. Установите инструмент для компиляции кода TypeScript:

	```bash
	npm install -g TypeScript
	```
	
4. Соберите проект:

   ```bash
   npm run compile
   ```
    
5. Установите инструмент vsce для упаковки расширения в формат VSIX:

    ```bash
   npm install -g @vscode/vsce
   ```

6. Упакуйте проект:

    ```bash
   vsce package
   ```

    В корне папке появится файл с расширением *.vsix


### Добавление расширения в VSCode

1. Откройте VSCode
2. Нажмите комбинацию клавиш `Ctrl+Shift+X` для перехода в раздел "Расширения"
3. В меню выберите "Установить из VSIX..." и выберите созданный файл
4. Перезапустите VSCode для применения изменений



В случае, если вы скачали готовый релиз, вам нужно только установить расширение в VSCode.
