
# История изменений

Здесь документируются все изменения проекта

## Версия 0.2.1 (2025-12-22)

### Исправления

- Существенно переделана функция создания терминала. Теперь он создаётся не при старте расширения, а после настройки путей `nuttx`.

## Версия 0.2.0 (2025-12-22)

### Исправления

- Исправлена критическая ошибка, не позволявшая вызывать общий для всех функций терминал.

## Версия 0.1.12 (2025-12-22)

### Исправления

- Удалено поле `publisher` из файла `package.json`.
- В файле `terminal.js` в функции `initTerminal` исправлено значение поля `cwd`. 

## Версия 0.1.11 (2025-12-22)

### Исправления

- Функция `Clean` теперь очищает проект без удаления конфигурационных файлов.
- Для полной очистки проекта добавлена функция `Clean all`.
- При появлении ошибки об отсутствии конфигурационных путей `nuttx` при выполнении команд `Clean` и `Clean all` стала доступнка их настройка.
- Исправлены импорта функции `configPaths` в файлах `cleanProject` и `cleanAllProject`.
- В раздел `activationEvents` файла `package.json` добавлено определение `onCommand:nuttx-helper.CleanAll`.
- В папку `icon` добавлены две кионки с расширением `.png` и `.svg`.
- В файл `package.json` добавлены поля `publisher` и `description` с соответствующим содержанием.
- В файле `extension.js` при старте расширения создаётся терминал, доступный для использования остальным командам. Это сделано 
во исбежания создания большого количество терминалов при выполнении команд, которые могли бы тратить оперативную память.

## Версия 0.1.7 (2025-12-17)

### Новые функции

Все функции имеют собственные комбинации клавиш для вызова. Полный список:
- `ctrl+shift+n` - создание нового проекта.
- `ctrl+shift+s` - выбор целевой платы или микроконтроллера.
- `ctrl+shift+m` - настройка целевой платы или микроконтроллера через `menuconfig`.
- `ctrl+shift+p` - настройка путей к папкам `apps` и `nuttx` дистрибутива Apache NuttX.
- `ctrl+shift+r` - настройка инсирумента записи программы в память микроконтроллера.
- `ctrl+shift+i` - вызов информаци о версии расширения.
- `ctrl+shift+с` - очистка проекта.
- `ctrl+shift+b` - компиляция проекта.

## Версия 0.1.3 (2025-12-12)

### Новые функции

- Добавлена команда **Configure paths** для настройки путей к директориям `apps` и `nuttx` дистрибутива `Apache NuttX`.
- Добавлена команда **Set board** для поиска и выбора целевой платы или микроконтроллера.
- Добавлена команда **Configure board** для вызова `menuconfig`.
- Добавлена команда **Create NuttX progect** для создания необходимой структуры файлов и папок проекта.
- Добавлена команда **Clean project** для очистки проекта.
- Добавлена команда **Build project** для сборки проекта.
- Добавлена команда **Information** для вывода версии расширения.
- Реализована возможность ввода команд через командную строку VSCode.
- Созданный проект автоматически добавляется в рабочую область редактора.
