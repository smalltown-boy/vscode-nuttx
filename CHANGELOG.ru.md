# История изменений

Здесь документируются все изменения проекта

## Версия 0.1.7 (2025-12-17)

### Новые функции

Все функции имеют собственные комбинации клавиш для вызова. Полный список:
- `ctrl+shift+n` - создание нового проекта.
- `ctrl+shift+s` - выбор целевой платы или микроконтроллера.
- `ctrl+shift+m` - настройка целевой платы или микроконтроллера через `menuconfig`.
- `ctrl+shift+p` - настройка путей к папкам `apps` и `nuttx` дистрибутива Apache NuttX.
- `ctrl+shift+r` - настройка инсирумента записи программы в память микроконтроллера.
- `ctrl+shift+i` - вызов информаци о версии расширения.
- `ctrl+shift+с` - очистка проекта.
- `ctrl+shift+b` - компиляция проекта.

## Версия 0.1.6 (2025-12-16)

### Разрабатываемые функции

- Реализован механизм выбора целевой архитектуры для функции **Run configurations**.
- Выбранная пользователем архитектура сохраняется в файле настроек расширения.
- Реализован механизм выбора инструментов программирования микроконтроллеров ARM для функции **Run configurations**.
- Выбранный пользователем инструмент сохраняется в файле настроек расширения.
- В файл package.json добавлены поля **selectedPlatform**, **selectedUSB** и **selectedTool**.

### Исправления

- В файле CHANGELOG.md исправлена ошибка в наименовании версии 0.1.5.

## Версия 0.1.4 (2025-12-12)

## Версия 0.1.3 (2025-12-12)

### Новые функции

- Добавлена команда **Configure paths** для настройки путей к директориям `apps` и `nuttx` дистрибутива `Apache NuttX`.
- Добавлена команда **Set board** для поиска и выбора целевой платы или микроконтроллера.
- Добавлена команда **Configure board** для вызова `menuconfig`.
- Добавлена команда **Create NuttX progect** для создания необходимой структуры файлов и папок проекта.
- Добавлена команда **Clean project** для очистки проекта.
- Добавлена команда **Build project** для сборки проекта.
- Добавлена команда **Information** для вывода версии расширения.
- Реализована возможность ввода команд через командную строку VSCode.
- Созданный проект автоматически добавляется в рабочую область редактора.
